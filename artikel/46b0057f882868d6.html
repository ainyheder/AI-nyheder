Microsofts Surface RTX Spark kan nu forudbestilles

Dev Box er en mini-pc til udviklere til omkring 6.000 dollar. Den sendes fra november med 128 GB unified memory.

01Kassen selv fungerer som køleribbe

Surface RTX Spark Dev Box er en mini-pc fra Microsoft, som er beregnet til udviklere. Den flade kasse er 3D-printet i anodiseret aluminium og fungerer selv som køler. Den ligner ventilationsåbningerne på toppen af en Xbox Series X.

Maskinen kører på Nvidias Arm-baserede RTX Spark-platform med 128 GB unified memory, altså hukommelse som processoren og grafikdelen deler. Den har et termisk effektloft på 100 watt og Nvidias Tensor-kerner, som er specialiserede processorkerner til AI-beregninger.

02Den kører AI-modeller over 120 milliarder parametre

Navnet Dev Box rammer plet: maskinen er især rettet mod udviklere. Den er optimeret til at køre AI lokalt, herunder modeller med mere end 120 milliarder parametre. Et parameter er én værdi, som et AI-model lærer under træning, og flere parametre betyder typisk en større model.

Den skal bruges til at teste AI-modeller, bygge prototyper på AI-agenter og køre AI-værktøjer til kode direkte på maskinen.

03Værktøjskassen er forudinstalleret

Dev Box hører til Microsofts Project Zenith-enheder. Den leveres med en Windows 11 Pro-installation, der er sat op til udviklere, sammen med forudinstallerede værktøjer: Visual Studio Code, Git, GitHub CLI, GitHub Copilot, WSL, Python og Node.

Maskinen kan forudbestilles nu til omkring 6.000 dollar og begynder at blive sendt i november. Den er dyrere end DGX Spark, den tilsvarende mini-pc, som Nvidia lancerede sidste år. Samtidig er pc-priserne steget på grund af mangel på RAM og andre komponenter.
