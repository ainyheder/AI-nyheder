GitHub: Merged pull requests tredoblet på et år

Octoverse-rapporten viser 220 mio. merged pull requests om måneden og 7,38 mia. commits – med størstedelen af stigningen i årets anden halvdel.

01Merged pull requests tredoblet på et år

På GitHub Universe præsenterede Jay Parikh, EVP i GitHub, selskabets årlige Octoverse-rapport. Det mest iøjnefaldende tal var 220 mio. merged pull requests om måneden – ændringsforslag til kode, som er accepteret og lagt ind i et projekt. Det er en tredobling på under et år.

Commits, altså de enkelte registrerede kodeændringer, mere end tredobledes til 7,38 mia. om måneden. Størstedelen af den stigning faldt i årets anden halvdel.

Simon Willison, der selv var til stede, kalder i sit referat tallene et tydeligt billede af, hvordan agentic engineering – når AI-agenter selv udfører dele af programmeringsarbejdet – har påvirket GitHub.

02Nye projekter fordoblet til 30,3 millioner

Også tilvæksten af nye repositories – de enkelte kodeopbevaringssteder på GitHub – steg markant. Ratten blev fordoblet i 2026 til 30,3 mio. om måneden.

Alle tre tal er GitHubs egne aktivitetsdata fra platformen, og de måler volumen, ikke hvad koden bruges til.

03Sådan har GitHub lavet opgørelserne

Rapportens metodedel beskriver flere nye opgørelser. For at rangere lande efter pushes til offentlige repositories brugte GitHub en LLM-klassificering til at udtrække landekoder fra brugernes profiler og dermed korrigere for VPN-brug.

Offentlige repositories oprettet 2022–2026 blev sorteret i brancher efter NAICS-systemet med en finjusteret flersproglig embedding-model, der læste navn, beskrivelse, emneord og README ud fra stikprøver.

Et tredje nyt mål tæller repositories, hvis tekst nævner interoperabilitet eller reverse engineering – for eksempel clean room-implementeringer, drop-in-erstatninger eller genimplementering af protokoller.
