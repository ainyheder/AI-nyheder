Claude får Docs og Slides i samme chat

Anthropic samler chatværktøjerne i »one Claude« og lader dig lave dokumenter og præsentationer direkte i samtalen. Betaen kommer først til Pro og Max.

01Dokumenter og slides fra chatten

Du kan fra i dag bede Claude om at lave et dokument eller en præsentation direkte i samtalen. De to nye værktøjer hedder Claude Docs og Claude Slides og lanceres i beta.

Indholdet kan eksporteres, redigeres og deles med andre brugere. Du kan bede Claude rette noget i det, den har lavet, eller rette det manuelt selv.

02Cowork smelter ind i Claude

Samtidig lægger Anthropic almindelige chats og Cowork sammen til det, selskabet kalder »one Claude«, så alle AI-produktivitetsværktøjer er tilgængelige fra enhver chat. Det gælder også Artifacts og Claude Design.

Anthropic formulerer det sådan, at Claude »nu kan finde ud af, hvad en opgave kræver«, så det, Cowork og Design kan, er tilgængeligt fra enhver samtale med de kontekster, færdigheder og forbindelser, man allerede har.

03Delt link i stedet for filer

Claude Docs starter som private dokumenter, ligesom i Google Docs. Du kan dele dem med andre redaktører, som kan arbejde i dokumentet samtidig med dig.

Både samarbejdspartnere og Claude kan efterlade kommentarer, der ligner dem, man kender fra Google Docs. Ifølge Anthropic ligger alt, man laver med Claude Design, Slides eller Docs, på ét delbart link, man kan åbne på sin telefon.

04Google har indbygget forspring

Anthropics modeller bliver generelt set som mere avancerede end Googles, men Googles AI-tjenester har fordelen af at være bygget direkte ind i Googles produktivitetsværktøjer.

Tidligere i år udvidede Google Geminis rolle i Google Docs, Sheets og Slides med blandt andet et Gemini-chatvindue i Docs, generering og redigering af hele dokumenter og slides med Gemini. Med Docs og Slides mindsker Claude afstanden til Googles værktøjskasse.

05Først til Pro og Max

Opdateringen med »one Claude« ruller først ud til Pro- og Max-brugere på web, desktop og mobil »i løbet af de næste par uger«. Team- og gratisbrugere får adgang senere.

Anthropic oplyser, at der ikke skal slås noget til for opdateringen, og at man fortsat kan bruge Claude-chatten, som man plejer.

Flere detaljer
  • Claude Docs og Slides lanceres i beta sammen med Claude Design.

  • Ifølge Anthropic skal der ikke slås noget til for opdateringen.
