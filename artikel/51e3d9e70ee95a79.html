Docker lancerer sikre sandkasser til AI-agenter

Docker har udgivet Sandboxes, der lader AI-agenter arbejde frit i isolerede miljøer uden at true din computer. Værktøjet er allerede klar til Claude Code, Copilot CLI og flere.

Det er sket

Docker har lanceret et nyt værktøj kaldet Sandboxes, der giver AI-agenter deres egen lille, afskærmede boks at arbejde i. Her kan agenterne installere programmer, ændre indstillinger og køre Docker-containere, uden at din egen computer røres. Du kan installere det på macOS, Windows og Linux med få kommandoer, og boksen kan smides væk igen med et enkelt klik.

Hvorfor det betyder noget

AI-agenter bliver hurtigere, når de får lov til at arbejde uden at spørge om lov hele tiden - den såkaldte 'YOLO mode'. Men det er risikabelt, hvis de kan rode i dine filer. Docker løser det ved at give hver agent sin egen mikroVM, der er startet på under et sekund. Det giver samme sikkerhed som en virtuel maskine, men meget hurtigere at starte.

Hvem kan bruge det

Værktøjet virker med de mest populære AI-kodningsværktøjer som Claude Code, Copilot CLI, Codex, OpenCode og Kiro. Docker siger, at man også kan lave sine egne. For virksomheder, der vil styre flere medarbejderes agenter centralt, findes der et ekstra produkt kaldet Docker AI Governance, som administrerer sikkerhedsreglerne på tværs af hele teamet.

Detaljerne
  • Docker Sandboxes kører hver AI-agent i en isoleret mikroVM med kun projektets filer monteret.
  • Installation kræver én kommando på henholdsvis macOS, Windows og Linux.
  • Understøtter Claude Code, Gemini CLI, Copilot CLI, Codex, OpenCode og Kiro.
  • Agenter kan selv starte Docker-containere inde i sandkassen.
  • YOLO mode lader agenter køre uden godkendelsesprompt, men nu sikkert isoleret.
  • Docker AI Governance giver centrale kontroller for netværk, filsystem og MCP.
Hvad betyder det for dig?
Du kan nu lade dine AI-agenter arbejde hurtigt og uden afbrydelser, mens din computer forbliver beskyttet mod utilsigtede ændringer eller skadelige kommandoer.
