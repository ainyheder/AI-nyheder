Docker Sandboxes: sikre legepladser til AI-agenter

Docker Sandboxes kører AI-agenter i isolerede mikroVMs. Understøtter Claude Code, Gemini CLI og Codex.

Hvad er det?

Docker Sandboxes er små, isolerede miljøer kaldet mikroVMs, hvor AI-agenter kan køre frit. Agenten kan installere programmer, ændre konfigurationer og starte sine egne Docker-containere, uden at dit system bliver rørt. Det er som at give agenten sin egen legeplads med høje mure.

Hvorfor nu?

AI-agenter bliver mere selvstændige og kan arbejde uden opsyn. Men den frihed er farlig uden beskyttelse. Docker Sandboxes giver sikkerhed, så agenter kan køre i såkaldt 'YOLO-tilstand', hvor de selv tager beslutninger, uden at du skal godkende hvert skridt.

Hvem er det til?

Værktøjet understøtter populære agenter som Claude Code, Gemini CLI, Copilot CLI, Codex og OpenCode. Det er bygget til teams, der vil give deres kodningsagenter frie tøjler, men stadig have kontrol over netværk og filsystemer.

Hvad koster det?

Du kan komme i gang gratis og installere værktøjet via brew på Mac eller winget på Windows. Docker tilbyder også et ekstra lag kaldet Docker AI Governance, som giver central styring for hele teams – men det kræver en ekstra løsning.

Detaljerne
  • Sandboxes er mikroVMs, som giver bedre isolation end almindelige VMs.
  • Agenter kan køre Docker-containere inde i sandkassen.
  • Understøtter Claude Code, Gemini CLI, Copilot CLI, Codex, Kiro og OpenCode.
  • Værktøjet er designet til at beskytte din filsystem og netværk.
  • Docker AI Governance giver centrale politikker for teams.
Hvad betyder det for dig?
Du kan nu lade AI-agenter arbejde hurtigt og autonomt, uden at de kan skade din computer – og det er gratis at komme i gang.
