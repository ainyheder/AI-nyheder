Binance lader ChatGPT og Claude handle med dine penge

Binance's nye Agent OS lader AI-værktøjer som ChatGPT og Claude Code handle krypto. Brugeren sætter grænserne.

Det er sket

Binance, verdens største kryptobørs med over 300 millioner brugere, har lanceret platformen Agent OS. Her kan AI-agenter analysere markeder og selv udføre handler på vegne af brugeren. Platformen virker sammen med kendte værktøjer som ChatGPT, Claude Code og Cursor.

Sådan styres det

Brugeren tildeler agenten en såkaldt underkonto, hvor der kan sættes begrænsninger. Udbetalinger er blokeret som standard, og agenten kan kræve godkendelse for hver handel eller handle frit inden for kontoens rammer. Binance kan ikke se agentens ræsonnement.

Pengene bag

Der er ingen særskilt grænse for, hvor meget en agent kan handle eller tabe på børsen. Agentic Wallet-transaktioner har dog daglige lofter: 50.000 dollars for swaps, 100.000 dollars for DeFi og kun 20 dollars for x402-betalinger.

Konkurrenterne

Binance er ikke alene. Kraken lancerede i marts et lignende værktøj, Coinbase fulgte i juni med Coinbase for Agents, og OKX har også åbnet for agent-handel. Kapløbet om at lade AI styre rigtige penge er for alvor i gang.

Detaljerne
  • Binance lancerede Agent OS den 20. august 2026.
  • Platformen understøtter ChatGPT, Codex, Claude Code og Cursor.
  • Underkonti blokerer udbetalinger som standard for at beskytte brugerens midler.
  • Brugeren kan vælge, om agenten skal godkende hver handel eller handle autonomt.
  • Binance kan ikke se, hvorfor agenten træffer en bestemt beslutning.
  • Kraken og Coinbase har også åbnet for AI-handel.
Hvad betyder det for dig?
Du får nu mulighed for at overlade dine kryptohandler til en AI-agent, men sikkerheden afhænger af, hvor godt du selv sætter grænserne op.
