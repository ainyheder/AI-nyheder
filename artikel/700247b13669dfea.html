Anthropic lader AI-kodeværktøj køre helt uden godkendelser

Anthropic gør auto-tilstand til standard for Claude Code fra 14. august. AI'en klarer opgaver selv, medmindre noget er uigenkaldeligt eller ødelæggende.

Det er sket

Anthropic gør auto-tilstanden til standard for Claude Code for Pro-, Max- og Team-konti fra 14. august. Tidligere skulle brugere godkende hvert trin manuelt, men nu kører AI'en videre, medmindre en handling er uigenkaldelig, ødelæggende eller rettet uden for dit miljø.

Testen viser

I en undersøgelse med 1.053 betalte testere opdagede auto-tilstanden 89 % af skadelige handlinger, mens menneskelig gennemgang kun fangede 13,6 %. Ifølge Anthropic bliver manuel gennemgang ofte en vane – brugerne godkender hele 97 % af godkendelsespromptene.

Sikkerheden

Anthropic har tilføjet nye sikkerhedsfunktioner som screening for prompt-injektioner og brugerdefinerede hårde afvisningsregler. Disse skal forhindre datatyveri og andre skadelige handlinger. Chefen for Claude Code, Boris Cherny, siger på X, at teamet kun bruger auto-tilstand og ikke kan forestille sig at gå tilbage.

Detaljerne
  • Auto-tilstand bliver standard for Pro-, Max- og Team-konti fra 14. august.
  • AI'en springer godkendelser over, medmindre handlingen er uigenkaldelig eller ødelæggende.
  • I test med 1.053 betalte testere var auto-tilstand mere effektiv end manuel gennemgang.
  • Boris Cherny, chef for Claude Code, bruger kun auto-tilstand og roser den.
  • Nye sikkerhedsforanstaltninger inkluderer screening for prompt-injektioner og hårde afvisningsregler.
  • Målet er at forhindre datatyveri og andre skadelige handlinger.
