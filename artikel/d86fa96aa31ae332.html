OpenAI lancerer Data agent i ChatGPT Work

OpenAI præsenterer en dataagent i ChatGPT Work, der via naturligt sprog kan forbinde virksomhedsdata og bygge interaktive dashboards.

Dataagent i ChatGPT Work

OpenAI har annonceret en ny funktion kaldet Data agent i ChatGPT Work. Ifølge OpenAI kan den forbinde virksomhedsdata, finde indsigter og bygge interaktive dashboards ved hjælp af AI og naturligt sprog. Annoncen er formuleret som en bred tilgængelighed, men kilden dokumenterer ikke pris, adgang eller test.

Naturligt sprog som grænseflade

Det bærende element er, at brugeren skal kunne arbejde med data gennem almindeligt sprog i stedet for manuel opsætning. Ifølge OpenAI dækker funktionen både at koble data til, udlede indsigter og sammensætte interaktive dashboards. Der er ikke oplyst tekniske begrænsninger, integrationsomfang eller hvilke datakilder der understøttes.
