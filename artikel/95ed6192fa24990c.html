Mistral Studio samler agenter og apps

Mistral AI udvider Mistral Studio med managed agents og apps, mens Mistral Large 4 skal gøre kodning, cybersikkerhed og dokumentanalyse klar til produktion.

01Le Chonk skal kode og læse dokumenter

Mistral AI har løftet Mistral Large 4 frem som en ny model til virksomheder. Modellen har tilnavnet Le Chonk og skal ifølge Mistral være stærk til kodning, defensiv cybersikkerhed og komplekse dokumenter og forretningsopgaver.

Den beskrives som en åben model, som virksomheder kan bygge videre på. Præcis hvor meget bedre den er end tidligere modeller, oplyser kilden ikke.

02Agenter og apps får fælles infrastruktur

Mistral Studio er platformen, hvor modellen sættes i arbejde. Den nye udvidelse tilføjer managed agents og apps — agenter og applikationer, som Studio hoster og kører — samt nye muligheder for workflows, virksomhedskontekst, overvågning og evalueringer.

En agent undersøger og handler, et workflow koordinerer trin og godkendelser, og en app giver medarbejderne adgang. Ifølge Mistral kan alle tre dele bygges på samme infrastruktur og knyttes til virksomhedens data via connectors og MCP-servere, som forbinder modellen med data og systemer.

03Én kommando sender koden i drift

Udviklere kan bygge med Mistral Vibe eller en eksisterende coding agent, teste lokalt og udrulle til Studio med én kommando, skriver Mistral. Studio står for hosting og kørsel.

Agenter kan få færdigheder, sandkasser til at køre kode og underagenter til at dele opgaver. Hooks lader udviklere indsætte egen logik undervejs, og et workflow kan genoptages efter afbrydelser.

04Mistral måler på timer og kunder

Mistral oplyser tre interne eksempler. En agent til produktionsfejl følger teamets runbook, spørger om lov før følsomme handlinger og poster fund i Slack; det sparer ifølge Mistral hundredvis af timer om måneden.

En workflow til idéer og kundefeedback sparer produktteamet cirka 35 timer om ugen. En staffing-app anbefaler folk med begrundelse. ABANCA, BNP Paribas og flere konsulenthuse bruger allerede Studio i produktion.

05Data kan blive i eget miljø

Studio kan køre i skyen, i virksomhedens egen VPC, on-premises eller i en blanding. Følsomme data og processer kan dermed holdes inden for virksomhedens eget perimeter, skriver Mistral.

OpenTelemetry-spor viser modelkald, værktøjer og godkendelser trin for trin, og evalueringer kan teste ændringer mod egne datasæt før udrulning.
