Slack lader hold kode sammen med AI

Slack lancerer dedikerede kanaler, hvor teams kan samarbejde med AI-agenter om kode. Funktionen hedder Slack Code og er tilgængelig fra i dag.

Nyt værktøj

Slack Code er en ny funktion, der giver hold et åbent rum til at arbejde med AI-agenter. I stedet for at hoppe mellem forskellige værktøjer og samtaler, kan teams nu tagge en agent som Anthropics Claude eller Cognitions Devin direkte i Slack. Agenten opretter så selv en kodekanal til opgaven, hvor alle kan se samtalen, gennemgå ændringer og godkende arbejdet, før det sendes ud.

Sådan virker det

Kodekanalerne lukker sig selv ned, når opgaven er løst, og gemmer et log over alt, hvad der er sket. Slack kalder det en nem måde at behandle AI-agenter som kolleger på. Funktionen virker med de agenter, der allerede findes i Slacks markedsplads, og partnere som GitHub Copilot og Vercel Agent er med fra starten.

Tilgængelig nu

Slack Code er allerede lanceret og kan bruges på alle Slack-planer. Det er et forsøg på at gøre det lettere for almindelige medarbejdere at få glæde af AI uden at skulle være tekniske eksperter. Samtidig viser det, at konkurrenter som SpaceXAI også forsøger at sælge idéen om AI-agenter som holdkammerater.

Detaljerne
  • Slack Code er lanceret i dag og tilgængelig på alle Slack-planer.
  • Kodekanaler oprettes automatisk, når en agent tagges i en besked.
  • Alle på holdet kan se samtaler, ændringer og forhåndsvisninger.
  • Kanalerne arkiverer sig selv, når opgaven er færdig.
  • Claude, Devin, Vercel Agent og GitHub Copilot er blandt partnerne.
  • Slack vil gøre AI-agenter til en naturlig del af samarbejdet.
Hvad betyder det for dig?
Du kan nu få AI til at løse kodningsopgaver direkte i Slack, hvor hele teamet kan følge med og godkende – uden at skulle skifte mellem programmer.
