ChatGPT, Grok og Claude ramt af samtidig nedbrud

Tre af de største AI-chatbots var nede samtidig torsdag. ChatGPT, Grok og Claude er nu oppe igen efter flere timers problemer.

Det er sket

Torsdag morgen begyndte ChatGPT at give fejlbeskeder for brugere, der forsøgte at chatte. Også logins, filuploads, voice mode og søgning blev ramt. Hos Anthropic gik Claude, Claude Code og API'en ned på grund af et 'infrastrukturproblem' - det blev løst omkring kl. 12:15 amerikansk tid.

Tre tjenester ramt

Også xAI's Grok oplevede udfald på både Android, iOS og web fra morgenstunden. Brugere på X fik beskeden 'denne model er overbelastet'. Alle tre tjenester er nu oppe igen, men det er uvist, om nedbruddene hænger sammen, og hvad der gik galt.

Detaljerne
  • ChatGPT var nede med 'elevated errors' fra omkring kl. 11 ET.
  • Nedbruddet ramte også logins, filuploads, voice mode og søgning.
  • Claude og Claude API havde problemer på grund af en infrastrukturfejl.
  • Grok var ramt af udfald på Android, iOS og web fra kl. 9:30 ET.
  • xAI gav beskeden 'denne model er overbelastet' til brugere.
  • OpenAI, xAI og Anthropic er kontaktet, men har ikke svaret.
Hvad betyder det for dig?
Når flere af de største AI-tjenester er nede samtidig, kan du risikere at stå uden adgang til din chatbot, når du har mest brug for den. Opdateringer og udfald kan ske uden varsel.
