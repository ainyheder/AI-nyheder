Anthropic lader Claude godkende kodeændringer

Udviklere kan opstille regler for, hvornår en AI-agent må godkende ændringer, og hvornår et menneske skal tage stilling.

01AI får ansvar for godkendelsen

Anthropic lancerer Claude Ship, en samling AI-agenter, der kan gennemgå, rette og godkende rutinemæssige ændringer i programkode. En AI-agent er her et værktøj, der kan udføre flere trin i en arbejdsopgave.

Det nye er især, at en agent kan få lov til at godkende ændringer efter regler, som udviklerholdet selv fastlægger. Kodegennemgang findes allerede i andre AI-værktøjer, men Anthropic lader dermed også en agent træffe beslutningen om godkendelse.

Baggrunden er, at AI-værktøjer kan skrive store mængder kode, som efterfølgende skal gennemgås og godkendes. Det arbejde kan blive en flaskehals, før ændringerne bliver en del af et program.

02Tre værktøjer deler kodearbejdet

Claude Ship består af Code Review, som gennemgår foreslåede kodeændringer, og to nye agenter. PR Steward tager sig blandt andet af fejl i automatiske kontroller, konflikter mellem kodeændringer og problemer, som Code Review finder.

Når PR Steward har sendt ændringer til projektet, kommenterer den, hvad den har ændret, og hvordan det kan rulles tilbage. Claude Approvals bruger derefter holdets godkendelsesregler, som skrives i almindeligt sprog i en fil i projektets kodelager.

Reglerne kan blandt andet tage højde for, hvad Code Review har fundet, eller virksomhedens egne systemer til at klassificere ændringer.

03Holdet bestemmer grænserne for agenten

Anthropic anbefaler, at hold først bruger godkendelsen i en tilstand, hvor agenten kun observerer. Holdene kan også begynde med ét kodelager og sætte månedlige udgiftsgrænser.

Ifølge Anthropic vælger holdene selv, hvor Claude Ship skal køre, hvor grundig gennemgangen skal være, og hvilke ændringer et menneske skal afgøre. Det giver holdet mulighed for at beholde menneskelig kontrol over udvalgte beslutninger.

Claude Ship rulles ud til Claude Team- og Enterprise-abonnementer for kodelagre på GitHub. Code Review er generelt tilgængeligt, mens PR Steward og Claude Approvals er i beta, altså en tidlig version.
