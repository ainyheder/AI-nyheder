Microsoft Copilot samler chat, kode og agenter

Én app med tre faner erstatter to separate Copilot-udgaver, og prisen afhænger nu af, hvor meget AI hvert medlem bruger.

01Tre faner samler Microsofts AI-arbejde

Microsoft har officielt lanceret en ombygget Copilot-app med tre faner: Home, Code og Autopilot. Home kombinerer Copilot Chat og Cowork og er standardsiden, brugerne lander på.

En planlagt Today-funktion skal samle vigtige mails, mødeindkaldelser og Teams-tråde i ét overblik. »Home er, hvor du finder dig til rette,« forklarer Jared Spataro, marketingchef for AI på arbejde hos Microsoft.

02Kodefane bygger interne apps i skyen

Code-fanen er den uventede tilføjelse. Den lader enhver lave en app, tracker, dashboard eller automation og dele resultatet med kolleger som en skyhostet intern app.

Ifølge Spataro kører fanen i et isoleret miljø – en sandbox – og bygger på samme teknologi som GitHub Copilot. Den er rettet mod vidensarbejdere, ikke kun programmører.

03Autopilot erstatter Scout som digital kollega

Autopilot hed tidligere Scout og var en desktop-app. Nu er det en skybaseret version, der kører videre, mens du sover, med sin egen cloud-computer.

Den kan holde øje med Teams-kanaler, køre tilbagevendende opgaver og håndtere opfølgninger. »Autopilot bor i din tenant med egen identitet, hukommelse, computer og arbejdsplads,« siger Spataro og kalder systemet bygget på Microsoft IQ.

04Prisen afhænger af AI-forbruget

Microsoft opkræver betaling efter forbrug for Cowork, Code og Autopilot. Langvarige agentopgaver og brug af modeller som Astra og Fable afregnes efter forbrug.

Det almindelige Copilot-licens dækker Chat samt Word, Excel, PowerPoint, Outlook og Teams. IT-administratorer får FinOps for AI til at styre udgifterne og holde agentforbruget under kontrol.

05Udrulning sker i tre faser

Home og Code ruller ud til Frontiers tidlige adgangsprogram »i de kommende uger.« Autopilot går i privat preview senere på måneden.

Code kommer også i preview til Microsoft 365 Premium- og Pro-abonnenter senere i år. Microsoft har angivet periodebeskrivelser, ikke faste datoer.

06Microsoft kalder Copilot et nyt styresystem

Satya Nadella kalder Copilot »et nyt styresystem for arbejde«, der spænder over alle modeller og opgaver. Spataro sammenligner ambitionen med Office i PC-æraen.

Men Copilot har tabt i forbrugermarkedet til Claude og ChatGPT. Microsoft satser nu på erhvervskunder og markedsfører appen som »AI bygget til arbejde.«

Flere detaljer
  • Scout blev vist frem på Microsofts Build-konferencen tidligere på året.
  • Copilot har været redesignet flere gange siden lanceringen som chatbot i Bing.
  • Microsoft udnævnte for første gang en samlet Copilot-chef efter ledelsesrokader.
  • Kundefanen Code hostes sikkerhedsmæssigt inden for kundens eget tenant.
Derfor er det interessantMicrosoft skifter fra faste licenser til forbrugsafregning for agentfunktioner, hvilket gør AI-budgettet afhængigt af, hvor meget hvert team reelt bruger.
