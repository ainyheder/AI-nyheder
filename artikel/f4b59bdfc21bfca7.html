Meta udfordrer med Muse Code til store kodebaser

Metas nye AI-værktøj Muse Code hjælper programmører med store kodeopgaver. Det er gratis at teste og kører flere agenter parallelt.

Det er sket

Meta har lanceret Muse Code, et AI-terminalværktøj til programmører, der skal klare hele opgaver i store kodebaser. Ifølge Mark Zuckerberg kan det planlægge ændringer, skrive kode og validere resultatet. Værktøjet er i beta og kan installeres med én kommando.

Sådan virker det

Muse Code bygger på Metas tidligere model Muse Spark. Når opgaven er stor, deler den arbejdet op i flere under-agenter, der arbejder parallelt i isolerede arbejdsområder. Zuckerberg siger, at din egen kode aldrig røres, og at de testede seks spilfunktioner uden kollisioner.

Pris og konkurrence

Meta vil positionere sig billigere end OpenAI's Codex og Anthropic's Claude Code. AI-chef Alexandr Wang siger, at det især er prismæssigt attraktivt for mange arbejdsgange. Meta satser stort på AI og er netop gået ind i virksomhedsmarkedet med kundeservice-agenter.

Detaljerne
  • Muse Code er i beta og kan installeres med en enkelt kommando.
  • Værktøjet er bygget på Metas kodemodel Muse Spark.
  • Store opgaver deles op i parallelle under-agenter i isolerede arbejdsområder.
  • Zuckerberg testede seks spilfunktioner bygget samtidigt uden kollisioner.
  • Meta konkurrerer med OpenAI's Codex og Anthropic's Claude Code.
  • Alexandr Wang leder Meta Superintelligence Labs og fremhæver prisen.
Hvad betyder det for dig?
Hvis Muse Code holder, hvad det lover, kan du få AI-hjælp til store kodeprojekter uden at betale kassen - og uden at risikere at ødelægge din egen kode.
