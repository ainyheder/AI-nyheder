Claude Code læser AGENTS.md, når filen mangler

Fra version 2.1.277 slår Claude Code op i AGENTS.md, hvis CLAUDE.md ikke findes i mappen. Understøttelsen bygger på et nyt mod-system.

01Nyt filnavn træder ind i mappen

Fra version 2.1.277 af Claude Code gælder en ny regel. Ligger der ingen CLAUDE.md-fil i en mappe, tjekker Claude Code for AGENTS.md og bruger den i stedet.

CLAUDE.md er den fil, et projekt hidtil har lagt i mappen for at fortælle Claude Code, hvordan den skal arbejde. Med den nye version kan AGENTS.md træde ind i samme rolle, når den første fil ikke er der. Rækkefølgen er fast: CLAUDE.md først, AGENTS.md som det næste.

02Indbygget mod kan senere tilpasses

Understøttelsen af AGENTS.md er ikke skrevet ind i Claude Code fra bunden. Ifølge citatet er den bygget oven på Claude Code mods, en kommende måde at tilpasse rammen omkring værktøjet.

Netop denne mod er indbygget og følger med. Men citatet peger fremad: Brugerne skal selv kunne bygge egne versioner af de projektinstruktioner, de ønsker. Det er altså et løfte om en kommende mulighed, ikke en beskrivelse af noget, der allerede virker.
