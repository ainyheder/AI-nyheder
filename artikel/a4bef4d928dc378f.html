Google lader dig tale med Gmail, Docs og Keep

Google udruller stemmeassistent-funktioner til Gmail, Docs og Keep, så du kan styre apps ved at tale. Funktionerne hedder Live og ligner Gemini Live.

Det er sket

Google har begyndt at udrulle nye stemmeassistent-funktioner kaldet Gmail Live, Docs Live og Keep Live. De lader dig tale med dine apps i realtid, så du kan finde og få opsummeret oplysninger uden at skulle skrive eller lede manuelt. Udrulningen sker globalt på mobil i engelsk version fra i dag.

Sådan virker det

Gmail Live finder svar på spørgsmål som "hvornår er mit barns næste skolearrangement" ved at søge i din indbakke og svare mundtligt med links i en tekst. Docs Live kan omdanne dine talte ideer til strukturerede dokumenter og hente oplysninger fra Gmail og Drive. Keep Live laver referater af dine noter og kan tilføje fx 'ingredienser til pesto' på din indkøbsliste.

Hvem får det?

Funktionerne blev præsenteret på Google I/O i maj, men er nu tilgængelige. Gmail Live findes på iOS og Android for brugere med Google AI Plus, Pro og Ultra. Docs Live og Keep Live kræver Pro og Ultra, og Keep Live er kun til Android, mens Docs er til begge styresystemer.

Hvad nu?

Business-kunder på Workspace må vente, da Google siger funktionerne 'kommer snart' til dem. Stemmestyringen er især praktisk, når du er på farten eller ikke kan skrive, og den skal gøre det lettere at få overblik uden at dykke ned i lange tråde.

Detaljerne
  • Gmail Live, Docs Live og Keep Live er de nye stemmeassistent-funktioner fra Google.
  • Funktionerne lader dig stille spørgsmål som 'hvornår er mit barns næste skolearrangement' og få svar mundtligt.
  • De blev først præsenteret på Google I/O i maj.
  • Udrulningen sker globalt på iOS og Android i engelsk version fra i dag.
  • Gmail Live er tilgængelig for AI Plus, Pro og Ultra-abonnenter.
  • Docs Live og Keep Live er kun for Pro og Ultra, og Keep Live er kun Android.
  • Workspace business-kunder får funktionerne 'snart', ifølge Google.
Hvad betyder det for dig?
Du kan snart styre din Gmail og Docs ved at tale, hvilket sparer tid, når du er på farten – men kun hvis du betaler for et AI-abonnement.
