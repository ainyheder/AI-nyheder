OpenAI fører GPT-Live-1 til API

OpenAI tilføjer stemmemodellen GPT‑Live‑1 til sit API med fuld-duplex samtaler, bedre instruktionsfølge, brugerdefinerede stemmer og telefonistøtte.

Stemme i API'et

OpenAI har annonceret GPT‑Live‑1 i sit API. Modellen beskrives af OpenAI som et skridt mod mere naturlige stemmeoplevelser, fordi den understøtter fuld-duplex samtaler, altså tale i begge retninger samtidig. Det er en anden måde at bygge stemmeagenter på end de tidligere, mere tur-baserede løsninger. Ifølge OpenAI er modellen også bedre til at følge instruktioner.

Stemmer og telefon

OpenAI oplyser, at GPT‑Live‑1 understøtter brugerdefinerede stemmer og telefoni. Det betyder, at udviklere ifølge OpenAI kan bygge stemmeoplevelser, hvor brugeren ringer ind over det almindelige telefonnæt, og hvor stemmen kan tilpasses. Hvordan stemmerne oprettes og styres, og hvilke telefontjenester der konkret understøttes, fremgår ikke af det tilgængelige materiale.

Detaljerne
  • Ifølge OpenAI giver GPT‑Live‑1 fuld-duplex tale i begge retninger samtidigt
  • OpenAI oplyser, at modellen følger instruktioner bedre end tidligere
  • Brugerdefinerede stemmer fremhæves af OpenAI som en funktion
  • Telefonistøtte er nævnt af OpenAI, men uden nærmere detaljer
