Microsofts Project Zenith rydder op i Windows

Microsoft lancerer Project Zenith: en særlig Windows-version til udviklere med mindre støj og værktøjer klar fra start.

Det er sket

Microsoft har døbt sin særlige udvikler-version af Windows 'Project Zenith'. Det er en opsætning, der følger med nye pc'er med mindst 64GB hukommelse, så udviklere kan køre store AI-modeller lokalt og ubegrænset. Den første maskine, en mini-pc fra AMD med Ryzen AI Halo-chips, blev præsenteret på messen IFA.

Hvad er anderledes?

Zenith slår alle Windows' distraktioner fra: ingen tip i startmenuen, ingen notifikationer fra synkronisering eller mappe-ikoner. Fil-udforskeren viser nu altid filendelser, skjulte filer og hele stien. Udviklerværktøjer som Visual Studio Code, GitHub Copilot og PowerToys er forinstalleret og klar med det samme.

Hvorfor nu?

Microsoft siger, at Project Zenith bygger på ønsker fra udviklere. Med AI, der ændrer måden, kode skrives på, vil de have en Windows, der ikke forstyrrer. Nogle af ændringerne, som at fjerne irriterende elementer, kunne dog med fordel rulle ud til alle Windows 11-brugere, ikke kun udviklere.

Detaljerne
  • Project Zenith er Microsofts navn på en udvikler-optimeret Windows-version.
  • Første enhed er en AMD-mini-pc med Ryzen AI Halo-chips, vist på IFA.
  • Flere Project Zenith-enheder med andre chips er på vej i de kommende måneder.
  • Værktøjer som Visual Studio Code og GitHub Copilot er forudinstalleret.
  • Windows' tip og notifikationer er slået fra for at mindske distraktion.
  • Fil-udforskeren viser altid filendelser, skjulte filer og fuld sti.
  • PowerToys' kommandopalet er aktiveret som standard.
Hvad betyder det for dig?
Du kan snart købe en pc, hvor Windows ikke forstyrrer dig med tips og reklamer - og hvor tunge AI-programmer kører direkte på din maskine uden skyen.
