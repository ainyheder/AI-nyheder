Cursor udfordrer GitHub med ny platform

AI-virksomheden Cursor lancerer Origin, en konkurrent til GitHub, efter mange nedbrud har frustreret udviklere.

Det er sket

Cursor, kendt for sin AI-kodeeditor, har lanceret platformen Origin. Den skal kunne alt det, GitHub bruges til: samarbejde om kode, håndtere pull-requests og opbevare kode i repositories. Origin kan også arbejde sammen med GitHub, så man kan synkronisere sine projekter mellem de to tjenester.

Derfor nu

Lanceringen kommer, lige som GitHub oplever store problemer. Samme dag som Origin blev lanceret, havde GitHub et seks timer langt globalt nedbrud med næsten 20 % fejlrate. Det seneste år har der været 257 nedbrud, hvilket har fået flere kendte brugere til at forlade platformen.

Kampen bliver hård

GitHub er dog en svær størrelse at slå. Ifølge egne tal bruger 180 millioner udviklere platformen, som blev grundlagt i 2007 og købt af Microsoft i 2012. Cursor har endnu ikke afsløret detaljer om sine AI-funktioner til Origin, men lover en større app-økosystem.

Detaljerne
  • Cursor er nu en del af SpaceX, ifølge artiklen.
  • Origin lanceres som et alternativ til GitHub.
  • Platformen kan synkronisere med eksisterende GitHub-repos.
  • GitHub havde et nedbrud på over seks timer samme dag.
  • Fejlraten under nedbruddet var næsten 20 procent.
  • GitHub blev grundlagt i 2007 og opkøbt af Microsoft i 2012.
  • Cursor lover 'agent native' funktioner til Origin snart.
Hvad betyder det for dig?
Du kan snart vælge et nyt sted at opbevare din kode, hvis GitHub fortsat driller. Det giver dig flere muligheder og lægger pres på GitHub for at forbedre sig.
